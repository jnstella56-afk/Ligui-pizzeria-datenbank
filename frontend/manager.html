Bestellverwaltung

Neue Bestellung anlegen

Erfassen Sie eine neue Bestellung, indem Sie den Tisch, den zuständigen Mitarbeiter, das gewünschte Produkt und die Menge auswählen.

Produktverwaltung

Neues Produkt hinzufügen

Erweitern Sie das Sortiment um ein neues Produkt. Bitte tragen Sie alle Produktinformationen vollständig ein.

Produktpreis ändern

Wählen Sie ein Produkt aus und tragen Sie den neuen Preis ein. Produkte aus noch offenen Bestellungen können aus Gründen der Datenkonsistenz nicht geändert werden.

Produkt deaktivieren

Deaktivieren Sie ein Produkt, wenn es vorübergehend nicht mehr angeboten werden soll. Frühere Bestellungen bleiben dabei vollständig erhalten.

Produkt reaktivieren

Aktivieren Sie ein zuvor deaktiviertes Produkt erneut, damit es wieder für neue Bestellungen verfügbar ist.

Produkt löschen

Bitte beachten Sie: Ein Produkt kann nur gelöscht werden, wenn es noch nicht in einer Bestellung verwendet wurde. Bereits verwendete Produkte sollten stattdessen deaktiviert werden.
